# BetterDiscordPlugins

A collection of BetterDiscord plugins.

![SeasonalMoments effects](./SeasonalMoments/assets/effects.gif)

| Plugin | Description |
| --- | --- |
| [SeasonalMoments](./SeasonalMoments) | Seasonal chat and call effects, birthday and New Year cards, weather, and optional particles that briefly settle on usernames. |

SeasonalMoments by [YarilaFox](https://canary.discord.com/channels/@me/657887591634305036).

## Installation

Download the `.plugin.js` file from a plugin folder and place it in `%appdata%\BetterDiscord\plugins`. Enable it in BetterDiscord's plugin settings.

SeasonalMoments documentation: [README](./SeasonalMoments/README.md).
